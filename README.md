# My personal Website

This project is a personal portfolio website that i am building as part of my stardance project.

The main purpose of this website is to create a place where i can introduce myself, share my interest in technology,document my learning journey, and showcase projects that i build in the future.

## Development process

My development process involves several steps.

First, I create or modify the HTML structure.

Next, I use CSS to control how the webpage looks.

After, I use javascript when the functionality or interaction is required.

I then open the website in a browser to test it.

If something does not work correctly, I return to code, identity the problem, make a change, and test the website again.

This process is helping me become more comfortable with programming and debugging.

    ## Challenges 

    One of the biggest challenges has been making the website look good on different screen sizes.

    A background image that looks good on laptop may not automatically look good on a phone.

    This has required me to experiment with CSS properties such as:

    - `background-size`
    - `background-position`
    - `background-repeat`
    -`min-height`
    -positioning properties
    spacing and layout properties

    Another challenge has been understanding how different parts of HTML, CSS, and JavaScript work together.

    ---

    ## What I Have Learned From the Challenges 

    The challenges have taught me that writing code is often a process of experimentation.

    Sometimes the first solution does not work.

    Sometimes changing one CSS property can affect several other parts of the webpage.

    Instead of giving up when something goes wrong, i am learning to break the problem down into smaller parts and test each possibilities.
